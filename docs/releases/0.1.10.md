Preview update for the unofficial Android client for Sill.

- Match the upstream iPad connection layout: a centered column up to 380 dp,
  two compact cards when space permits, and a 92 dp preview area.
- Replace the README phone image with a live Pixel 6 desktop-session capture.
- Update the Xiaomi Pad 7 screenshot to show the corrected compact grid.
- Include the four-digit pairing-code grouping introduced in 0.1.8.

Download `sill-android-0.1.10.apk`. It updates earlier public releases in place
using the same signing key. Android 11 or later and a compatible HEVC decoder
are required. This remains an experimental, independently maintained client;
frame pacing and iOS feature parity remain incomplete.
