Preview update for the unofficial Android client for Sill.

- Replace the launcher icon with a grayscale Android robot inside the original
  Sill monitor composition, without the inner tablet frame.
- Use the same artwork as the README project logo and include source attribution.
- Retain the compact iPad-style connection layout and grouped pairing-code input.

Download `sill-android-0.1.11.apk`. It updates earlier public releases in place
using the same signing key. Android 11 or later and a compatible HEVC decoder
are required. This remains an experimental, independently maintained client;
frame pacing and iOS feature parity remain incomplete.
