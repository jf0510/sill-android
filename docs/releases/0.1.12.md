Preview update for the unofficial Android client for Sill.

- Restore HEVC decoder configuration after a queue-recovery flush. This addresses
  startup black screens where Desktop is selected and frames arrive but the
  decoder produces no picture until Desktop is selected again.
- Replace both README screenshots with the supplied live phone and tablet sessions.
- Retain the grayscale Android robot launcher icon and README logo from 0.1.11.

Download `sill-android-0.1.12.apk`. It updates earlier public releases in place
using the same signing key. Android 11 or later and a compatible HEVC decoder
are required. This remains an experimental, independently maintained client;
frame pacing and iOS feature parity remain incomplete.
