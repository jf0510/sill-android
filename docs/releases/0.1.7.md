Initial public preview of an unofficial Android client for Sill. This project is
independently maintained and is not endorsed by the upstream Sill author.

## Install

Download `sill-android-0.1.7.apk` below. Android 11 or later and a compatible HEVC
decoder are required. The Mac must run Sill and be reachable on the same network.
Development testing used Sill for Mac 0.6.0.

This APK uses the project's release signing key. Future release APKs can update
it in place. If you installed a local debug build with the same application ID,
uninstall that build first; this removes its local settings and pairing records.
The application ID is `io.github.jf0510.sill`.

## Included

- Mac discovery and code pairing using TLS and pinned device identities.
- Desktop and window streaming through Android hardware HEVC decoding.
- Touch controls, portrait trackpad, window selection, and basic software keyboard.
- Connection recovery and decoder-size fallback to Standard resolution.
- Phone and tablet layouts and independent Android launcher artwork.

## Preview limitations

Frame pacing remains device- and network-dependent. This preview does not provide
full iOS parity: audio, clipboard synchronization, AWDL, automatic USB pairing,
and complete hardware keyboard and stylus handling are not implemented.
Capture settings are shared with other clients connected to the Mac.

Development builds were exercised on Pixel 6 and Xiaomi Pad 7. Automated tests
cover protocol fixtures, session policy, input coalescing, and recovery behavior;
they do not establish performance across all Android devices.

`SHA256SUMS.txt` contains the APK checksum. Report Android-specific issues in this
repository and redact pairing codes and personal network details from logs.
