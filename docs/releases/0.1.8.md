Preview update for the unofficial Android client for Sill.

- Display pairing codes in three groups of four digits, matching the iOS client.
- Accept pasted codes with spaces or hyphens and retain at most 12 digits.
- Preserve cursor positions and deletion behavior at group boundaries.
- Provision Android SDK tools explicitly in CI and release builds.
- Add a Pixel 6 connection screenshot to the README using demo hosts.

Download `sill-android-0.1.8.apk`. It updates the 0.1.7 release in place using the
same signing key. Android 11 or later and a compatible HEVC decoder are required.
This remains an experimental, independently maintained client; frame pacing and
iOS feature parity remain incomplete. See the README for setup and limitations.
