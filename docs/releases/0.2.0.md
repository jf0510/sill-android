# Sill for Android 0.2.0

An experimental, unofficial Android client. This update catches up with Sill's
0.6.1 behavior and selected 0.6.2 development features (upstream `bf69067`).

- Full Screen, with left-edge/Back/Show controls return; optional Picture in Picture.
- Desktop button cycles the Mac's displays when supported; phone Larger Picture.
- Mac audio through AAC-ELD decoding, local mute and shared Send Audio control.
- Text clipboard in both directions. Paste on Mac waits for acknowledgement before
  issuing the paste shortcut; background/PiP/locked sessions do not share copies.
- Off-console read-only viewing and a 10-minute idle hold before system auto-lock.
- QR scanning and pairing links, signed saved-address updates, remembered VPN
  routes and recognition of newly paired Macs after their LAN address changes.
- Hardware keyboard down/up and repeat, mouse/wheel and stylus pointer input,
  configurable hold-to-drag, three/four-finger gestures and Mac cursor images.
- Local CJK composition, modifier shortcuts, menu merging, settings confirmation,
  a first-run tour and visible version labels.

Validation: 47 passing JVM tests, lint, formatting and debug/release builds; Xiaomi Pad 7 live
interoperability with upstream's synthetic TLS host, two displays, bidirectional clipboard and paste
receipt, composition/key input, audio output, full screen, PiP and off-console view.
See [testing](https://github.com/jf0510/sill-android/blob/main/docs/testing.md).

Audio remains experimental and device-dependent. Physical keyboards/styluses,
camera QR capture, real WAN/VPN paths and Pixel 6 were not re-tested. Apple AWDL
and automatic USB pairing are not Android features; this client uses LAN/VPN TLS.
PiP and system gestures vary by Android vendor. This is not a claim of complete
behavioral parity on every iPhone/iPad or Android configuration.

Install the APK over an earlier release-signed version to retain pairing. A debug
installation has a different signature and cannot be replaced in place by this APK.
